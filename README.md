## 核心功能

*   **自訂介面色板：** 全面調整遊戲內 HUD、地圖、物品欄等介面的透明度、大小與顏色，打造最符合您習慣的資訊佈局。
*   **效能最佳化設定：** 透過智慧預設配置與進階選項，優化遊戲的圖形渲染負載，提升幀率穩定性，減少延遲。
*   **穩定性增強模組：** 包含經過測試的補丁，旨在解決已知的遊戲崩潰、記憶體洩漏或特定硬體相容性問題。
*   **顯示設定調整工具：** 超越遊戲內建選項，提供對陰影質量、後處理效果、視野距離等參數的更精細控制。
*   **使用者介面簡化：** 提供「戰鬥模式」、「休閒模式」等預設方案，一鍵切換以隱藏不必要的介面元素，獲得更沉浸的視野。

## 常見問題 (FAQ)

**問：本工具支援哪些作業系統？**
答：Fortnite Visual Toolkit Pro 僅支援 64 位元的 Windows 10 與 Windows 11 系統。它不適用於 macOS、Linux 或任何行動裝置平台。

**問：使用本工具會導致我的遊戲帳號被封鎖嗎？**
答：本工具僅修改遊戲的視覺設定與本地介面文件，不涉及任何遊戲記憶體、網路封包或自動化操作，設計上完全符合遊戲服務條款。然而，我們強烈建議您在使用任何第三方工具前，自行瞭解並承擔風險。

**問：安裝或執行時出現錯誤，我該怎麼辦？**
答：請先確保您的 Windows 系統已更新至最新版本，並暫時關閉防毒軟體（將工具加入信任清單）。若問題持續，請嘗試以系統管理員身份運行安裝程式或主程式，並檢查下載的安裝檔案是否完整。更多協助請參閱專案的 Issues 區頁。

**問：這是一個付費工具嗎？**
答：否。Fortnite Visual Toolkit Pro 是一個免費的社群驅動專案，您可以自由下載與使用。
